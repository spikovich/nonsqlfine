## 📋 Описание проекта

Система представляет собой полнофункциональное веб-приложение для синхронизации данных в реальном времени между тремя компьютерами, соединенными кабельной локальной сетью. Приложение использует централизованную архитектуру (клиент-сервер) с WebSocket для мгновенной синхронизации изменений.

### ✨ Ключевые возможности:

- ✅ **Реал-тайм синхронизация** - изменения на одном компьютере мгновенно отображаются на всех остальных
- ✅ **CRUD операции** - создание, чтение, обновление и удаление записей
- ✅ **Работа в локальной сети** - не требует подключения к интернету
- ✅ **Простой интерфейс** - интуитивно понятный UI с визуальной обратной связью
- ✅ **Индикация состояния** - показывает статус подключения и количество активных клиентов
- ✅ **Кабельное соединение** - надежное Ethernet подключение

## 🚀 Быстрый старт

### Предварительные требования:

- Node.js версии 18 или выше
- 3 компьютера с сетевыми картами
- Ethernet кабели и роутер/коммутатор
- Любая современная ОС (Windows, Linux, macOS)

### Шаг 1: Установка зависимостей

**На компьютере, который будет сервером:**
```bash
cd server
npm install
```

**На всех компьютерах (включая сервер):**
```bash
cd client
npm install
```

### Шаг 2: Настройка сервера

1. Узнайте IP-адрес компьютера-сервера:
   ```bash
   # Windows
   ipconfig
   
   # Linux/Mac
   ip addr
   ```

2. Запустите сервер:
   ```bash
   cd server
   npm start
   ```

### Шаг 3: Настройка клиентов

1. На каждом компьютере отредактируйте файл `client/.env`:
   ```env
   VITE_SERVER_URL=http://192.168.1.103:3000
   ```
   (Замените на IP-адрес вашего сервера)

2. Запустите клиент:
   ```bash
   cd client
   npm run dev
   ```

3. Откройте браузер: `http://localhost:5173`

### Шаг 4: Тестирование

1. Создайте запись на одном компьютере
2. Убедитесь, что она появилась на всех остальных
3. Попробуйте редактировать и удалять записи с разных компьютеров

✅ **Готово!** Система работает.

## 📡 API и протоколы

### REST API Endpoints:

| Метод | URL | Описание |
|-------|-----|----------|
| `GET` | `/api/items` | Получить все записи |
| `POST` | `/api/items` | Создать новую запись |
| `PUT` | `/api/items/:id` | Обновить запись |
| `DELETE` | `/api/items/:id` | Удалить запись |

### WebSocket Events:

| Event | Направление | Описание |
|-------|-------------|----------|
| `connection` | Client → Server | Клиент подключился |
| `disconnect` | Client → Server | Клиент отключился |
| `item_created` | Server → Client | Создана новая запись |
| `item_updated` | Server → Client | Запись обновлена |
| `item_deleted` | Server → Client | Запись удалена |
| `clients_count` | Server → Client | Количество подключенных клиентов |

## 🛠️ Устранение неполадок

### Проблема: Клиент не подключается к серверу

**Решение:**
1. Проверьте, что сервер запущен
2. Убедитесь, что IP-адрес в `.env` правильный
3. Проверьте файрвол (порт 3000 должен быть открыт)
4. Убедитесь, что все компьютеры в одной сети

### Проблема: Изменения не синхронизируются

**Решение:**
1. Проверьте индикатор подключения (должен быть зеленым)
2. Откройте консоль браузера (F12) и проверьте ошибки
3. Перезапустите клиенты и сервер

### Проблема: Порт 3000 занят

**Решение:**
Измените порт в `server/.env`:
```env
PORT=3001
```
И обновите адрес в `client/.env`:
```env
VITE_SERVER_URL=http://192.168.1.103:3001
```

## 🔒 Безопасность

Для учебного проекта в локальной сети:
- ❌ Аутентификация не реализована
- ❌ HTTPS не используется (только HTTP)
- ✅ Доступ ограничен локальной сетью
- ✅ Файрвол на сервере контролирует доступ

**Для продакшена потребуется:**
- Аутентификация пользователей
- HTTPS (SSL/TLS)
- Валидация данных на сервере
- Rate limiting
- Шифрование базы данных
