# Клиент системы синхронизации данных

## 📦 Установка

1. Убедитесь, что установлен Node.js (версия 18 или выше):
   ```bash
   node --version
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

## ⚙️ Настройка

### Важно: Укажите адрес сервера!

Создайте файл `.env` (или отредактируйте существующий):

```env
VITE_SERVER_URL=http://192.168.1.100:3000
```

Где `192.168.1.100` - это IP-адрес компьютера, на котором запущен сервер.

### Как узнать IP-адрес сервера:

**Windows:**
```bash
ipconfig
```
Ищите "IPv4-адрес"

**Linux/Mac:**
```bash
ip addr
# или
ifconfig
```

## 🚀 Запуск

### Режим разработки:
```bash
npm run dev
```

Клиент будет доступен по адресу:
- Локально: `http://localhost:5173`
- В локальной сети: `http://[IP-этого-компьютера]:5173`

### Сборка для продакшена:
```bash
npm run build
```

Собранные файлы появятся в папке `dist/`

## 🌐 Доступ с других компьютеров

Клиент автоматически настроен для доступа из локальной сети.

1. Узнайте IP-адрес этого компьютера (где запущен клиент):
   - Windows: `ipconfig`
   - Linux/Mac: `ip addr` или `ifconfig`

2. На других компьютерах откройте браузер и введите:
   ```
   http://[IP-адрес-клиента]:5173
   ```

Например: `http://192.168.1.101:5173`

## 🎯 Использование

### Создание записи:
1. Заполните форму "Название" и "Описание"
2. Нажмите "➕ Создать"
3. Запись появится на всех подключенных клиентах

### Редактирование записи:
1. Нажмите "✏️ Изменить" на нужной записи
2. Измените данные в форме
3. Нажмите "💾 Сохранить"

### Удаление записи:
1. Нажмите "🗑️ Удалить" на нужной записи
2. Подтвердите удаление

## 📊 Индикаторы

- **🟢 Зеленый индикатор** - подключено к серверу
- **🔴 Красный индикатор** - нет подключения к серверу
- **👥 Счетчик клиентов** - показывает, сколько компьютеров подключено

## 🛠️ Устранение неполадок

**Проблема:** "Не удалось подключиться к серверу"  
**Решение:**
1. Проверьте, что сервер запущен
2. Проверьте адрес в `.env` файле
3. Убедитесь, что компьютеры в одной сети
4. Проверьте файрвол на сервере (порт 3000 должен быть открыт)

**Проблема:** Изменения не синхронизируются  
**Решение:**
1. Проверьте индикатор подключения (должен быть зеленым)
2. Откройте консоль браузера (F12) и проверьте ошибки
3. Перезапустите клиент и сервер

**Проблема:** Не могу подключиться с другого компьютера  
**Решение:**
1. Убедитесь, что клиент запущен с флагом `--host` (автоматически в `npm run dev`)
2. Проверьте, что компьютеры в одной сети
3. Проверьте файрвол
