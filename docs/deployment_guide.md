## 🔌 Подготовка оборудования

### Что понадобится:

| Оборудование | Количество | Примечание |
|--------------|------------|------------|
| Компьютеры | 3 шт. | Windows/Linux/Mac |
| Ethernet кабели | 4 шт. | Cat5e или выше |
| Роутер или коммутатор | 1 шт. | С 4+ портами |

### Два варианта подключения:

#### **Вариант 1: Через роутер/коммутатор (РЕКОМЕНДУЕТСЯ)** ✅

```
┌──────────────┐
│ Компьютер 1  │──── Кабель 1 ────┐
└──────────────┘                  │
                                  │
┌──────────────┐                  │      ┌──────────┐
│ Компьютер 2  │──── Кабель 2 ────┼──────┤  Роутер  │
└──────────────┘                  │      └──────────┘
                                  │
┌──────────────┐                  │
│ Компьютер 3  │──── Кабель 3 ────┘
│  (Сервер)    │
└──────────────┘
```

**Шаги:**
1. Подключите все 3 компьютера к роутеру/коммутатору Ethernet кабелями
2. Убедитесь, что на роутере включен DHCP (обычно включен по умолчанию)
3. Компьютеры автоматически получат IP-адреса в одной сети

**IP-адреса (примерные):**
- Компьютер 1: `192.168.1.101`
- Компьютер 2: `192.168.1.102`
- Компьютер 3 (Сервер): `192.168.1.103`

#### **Вариант 2: Прямое соединение** (сложнее)

Для прямого соединения 3 компьютеров без роутера потребуется дополнительное оборудование (второй сетевой адаптер на одном ПК) или более сложная настройка. **Не рекомендуется для начинающих.**

## 💻 Установка ПО

### Требования к ПО (на всех компьютерах):

#### 1. Node.js (версия 18 или выше)

**Windows:**
1. Скачайте установщик: https://nodejs.org/
2. Запустите установщик
3. Следуйте инструкциям (выберите "Add to PATH")
4. Проверка:
   ```cmd
   node --version
   npm --version
   ```

**Linux (Ubuntu/Debian):**
```bash
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs
node --version
npm --version
```

**macOS:**
```bash
# С помощью Homebrew
brew install node@18
node --version
npm --version
```

#### 2. Git (опционально, для клонирования)

**Windows:** https://git-scm.com/download/win  
**Linux:** `sudo apt install git`  
**macOS:** `brew install git`

## 🖥️ Настройка сервера

**Сервер запускается на одном из трех компьютеров** (например, Компьютер 3).

### Шаг 1: Копирование файлов

Скопируйте папку `server/` на компьютер, который будет сервером.

### Шаг 2: Установка зависимостей

Откройте терминал/командную строку в папке `server/`:

```bash
cd server
npm install
```

Подождите, пока установятся все зависимости (~2-3 минуты).

### Шаг 3: Узнайте IP-адрес сервера

**Windows:**
```cmd
ipconfig
```
Найдите строку "IPv4-адрес" (обычно начинается с `192.168.` или `10.`)

**Linux/Mac:**
```bash
ip addr show
# или
ifconfig
```
Найдите IP-адрес интерфейса (обычно `eth0` или `wlan0`)

**Пример:** `192.168.1.103`

📝 **Запишите этот IP-адрес! Он понадобится для настройки клиентов.**

### Шаг 4: Настройка файрвола

Необходимо разрешить входящие подключения на порт 3000.

#### Windows:

1. Откройте "Параметры Windows"
2. Перейдите в "Безопасность Windows" → "Брандмауэр и защита сети"
3. Нажмите "Дополнительные параметры"
4. Выберите "Правила для входящих подключений"
5. Нажмите "Создать правило"
6. Выберите "Для порта" → Далее
7. Выберите "TCP", укажите порт `3000` → Далее
8. Выберите "Разрешить подключение" → Далее
9. Выберите все профили (Доменный, Частный, Публичный) → Далее
10. Укажите имя: "Node.js Server Port 3000" → Готово

#### Linux (Ubuntu/Debian):

```bash
sudo ufw allow 3000/tcp
sudo ufw status
```

#### macOS:

```bash
# Файрвол обычно не требует настройки для локальной сети
# Если включен, разрешите подключения в:
# Системные настройки → Защита и безопасность → Брандмауэр
```

### Шаг 5: Запуск сервера

В папке `server/` выполните:

```bash
npm start
```

Вы должны увидеть:

```
╔════════════════════════════════════════════════╗
║   🚀 СЕРВЕР СИНХРОНИЗАЦИИ ЗАПУЩЕН             ║
╟────────────────────────────────────────────────╢
║   📡 HTTP API:     http://localhost:3000       ║
║   🔌 WebSocket:    ws://localhost:3000         ║
║   💾 База данных:  SQLite (database.db)        ║
╟────────────────────────────────────────────────╢
║   Для доступа с других компьютеров:            ║
║   Используйте IP-адрес этого компьютера        ║
║   Пример: http://192.168.1.103:3000            ║
╚════════════════════════════════════════════════╝
```

✅ **Сервер запущен!** Оставьте это окно терминала открытым.

## 💻 Настройка клиентов

**Клиенты запускаются на всех трех компьютерах** (включая тот, где запущен сервер).

Повторите эти шаги на каждом из 3 компьютеров:

### Шаг 1: Копирование файлов

Скопируйте папку `client/` на каждый компьютер.

### Шаг 2: Установка зависимостей

Откройте терминал/командную строку в папке `client/`:

```bash
cd client
npm install
```

### Шаг 3: Настройка адреса сервера

Откройте файл `.env` в папке `client/`:

```env
VITE_SERVER_URL=http://192.168.1.103:3000
```

❗ **Замените `192.168.1.103` на IP-адрес вашего сервера** (который вы записали на Шаге 3 настройки сервера).

### Шаг 4: Запуск клиента

В папке `client/` выполните:

```bash
npm run dev
```

Вы увидите:

```
  VITE v5.0.8  ready in 500 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.1.101:5173/
```

### Шаг 5: Открытие в браузере

Откройте браузер и перейдите по адресу `http://localhost:5173`

✅ **Клиент запущен!** Вы должны увидеть интерфейс приложения.

## 🧪 Тестирование

### Проверка подключения:

1. **На каждом клиенте проверьте индикатор подключения:**
   - 🟢 Зеленый кружок и надпись "Подключено" - ✅ OK
   - 🔴 Красный кружок и надпись "Отключено" - ❌ Проблема

2. **Проверьте количество подключенных клиентов:**
   - Должно показывать число 3 (или сколько клиентов вы запустили)

### Тестирование синхронизации:

#### Тест 1: Создание записи

1. На **Компьютере 1**: создайте новую запись
   - Название: "Тест с Компьютера 1"
   - Описание: "Это тестовая запись"
   - Нажмите "➕ Создать"

2. **Проверьте:** запись должна появиться на всех трех компьютерах **мгновенно**

#### Тест 2: Редактирование записи

1. На **Компьютере 2**: отредактируйте запись, созданную на Компьютере 1
   - Нажмите "✏️ Изменить"
   - Измените название на "Изменено с Компьютера 2"
   - Нажмите "💾 Сохранить"

2. **Проверьте:** изменения должны отобразиться на всех компьютерах

#### Тест 3: Удаление записи

1. На **Компьютере 3**: удалите запись
   - Нажмите "🗑️ Удалить"
   - Подтвердите удаление

2. **Проверьте:** запись должна исчезнуть на всех компьютерах

### Ожидаемый результат:

✅ Все операции (создание, редактирование, удаление) мгновенно синхронизируются между компьютерами  
✅ Индикатор подключения зеленый на всех клиентах  
✅ Счетчик клиентов показывает 3

## 🔧 Устранение неполадок

### Проблема 1: Клиент показывает "Отключено" (красный индикатор)

**Возможные причины и решения:**

1. **Сервер не запущен**
   - Проверьте: открыто ли окно терминала с сервером?
   - Решение: запустите сервер (`npm start` в папке `server/`)

2. **Неправильный адрес сервера**
   - Проверьте: файл `.env` в папке `client/`
   - Убедитесь, что IP-адрес правильный
   - Решение: исправьте и перезапустите клиент

3. **Файрвол блокирует подключение**
   - Проверьте: настройки файрвола на сервере
   - Решение: разрешите порт 3000 (см. Шаг 4 настройки сервера)

4. **Компьютеры не в одной сети**
   - Проверьте: IP-адреса всех компьютеров
   - Должны быть в одной подсети (например, все `192.168.1.xxx`)
   - Решение: подключите все компьютеры к одному роутеру

### Проблема 2: Сервер не запускается

**Ошибка:** "Port 3000 is already in use"
- **Причина:** порт 3000 занят другой программой
- **Решение:** 
  - Закройте программу, использующую порт 3000
  - ИЛИ измените порт в файле `server/.env`: `PORT=3001`

**Ошибка:** "Cannot find module 'express'"
- **Причина:** не установлены зависимости
- **Решение:** выполните `npm install` в папке `server/`

### Проблема 3: Изменения не синхронизируются

1. **Проверьте индикатор подключения** на всех клиентах (должен быть зеленым)
2. **Откройте консоль браузера** (нажмите F12):
   - Должны быть сообщения: `✅ WebSocket подключен`
   - Не должно быть красных ошибок
3. **Перезапустите клиенты и сервер**

### Проблема 4: Не могу подключиться с другого компьютера

1. **Проверьте IP-адреса:**
   ```bash
   # На сервере
   ping 192.168.1.101  # IP клиента
   
   # На клиенте
   ping 192.168.1.103  # IP сервера
   ```
   Должны быть ответы.

2. **Проверьте физическое подключение:**
   - Все кабели подключены?
   - Индикаторы на сетевых портах горят?

3. **Попробуйте временно отключить файрвол** (для диагностики)

### Проблема 5: Низкая скорость или задержки

- **Причина:** перегруженная сеть или медленный компьютер
- **Решение:** 
  - Закройте ненужные программы
  - Используйте проводное подключение (Ethernet), а не Wi-Fi
  - Убедитесь, что компьютеры соответствуют минимальным требованиям

## 📊 Диагностика сети

### Проверка подключения между компьютерами:

1. **Узнайте IP-адреса всех компьютеров:**
   ```bash
   # Windows
   ipconfig
   
   # Linux/Mac
   ip addr
   ```

2. **Проверьте связь (ping):**
   ```bash
   # С Компьютера 1 проверьте Компьютер 2
   ping 192.168.1.102
   
   # С Компьютера 1 проверьте Компьютер 3
   ping 192.168.1.103
   ```

   **Ожидаемый результат:**
   ```
   Ответ от 192.168.1.102: число байт=32 время<1мс TTL=64
   ```

3. **Проверьте доступность сервера:**
   ```bash
   # Откройте браузер на клиенте и перейдите:
   http://192.168.1.103:3000/api/items
   ```
   
   Должен открыться JSON с данными: `{"items": [...]}`

## 🔄 Остановка системы

   - В каждом окне терминала клиента нажмите `Ctrl+C`
