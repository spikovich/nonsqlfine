# Сервер синхронизации данных

## 📦 Установка

1. Убедитесь, что установлен Node.js (версия 18 или выше):
   ```bash
   node --version
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

## 🚀 Запуск

### Обычный запуск:
```bash
npm start
```

### Запуск в режиме разработки (автоперезагрузка):
```bash
npm run dev
```

## 🌐 Настройка для локальной сети

### Шаг 1: Узнайте IP-адрес компьютера

**Windows:**
```bash
ipconfig
```
Ищите строку "IPv4-адрес" - например: `192.168.1.100`

**Linux/Mac:**
```bash
ip addr
# или
ifconfig
```

### Шаг 2: Разрешите доступ через файрвол

**Windows:**
- Откройте "Параметры Windows" → "Безопасность Windows" → "Брандмауэр и защита сети"
- Нажмите "Дополнительные параметры"
- "Правила для входящих подключений" → "Создать правило"
- Выберите "Для порта" → TCP → 3000
- Разрешить подключение

**Linux (ufw):**
```bash
sudo ufw allow 3000
```

### Шаг 3: Запустите сервер

Сервер будет доступен по адресу:
- Локально: `http://localhost:3000`
- В локальной сети: `http://[ваш-IP]:3000`

## 📡 API Endpoints

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/api/items` | Получить все записи |
| POST | `/api/items` | Создать новую запись |
| PUT | `/api/items/:id` | Обновить запись |
| DELETE | `/api/items/:id` | Удалить запись |

## 🔌 WebSocket События

- `connection` - клиент подключился
- `disconnect` - клиент отключился
- `item_created` - создана новая запись
- `item_updated` - запись обновлена
- `item_deleted` - запись удалена
- `clients_count` - обновление количества подключенных клиентов

## 📁 Файлы

- `server.js` - основной файл сервера
- `database.db` - SQLite база данных (создается автоматически)
- `.env` - конфигурация
- `package.json` - зависимости

## 🛠️ Устранение неполадок

**Проблема:** Порт 3000 уже занят  
**Решение:** Измените PORT в файле `.env`

**Проблема:** Клиенты не могут подключиться  
**Решение:** 
1. Проверьте, что сервер запущен
2. Проверьте IP-адрес сервера
3. Убедитесь, что файрвол разрешает подключения к порту 3000
4. Проверьте, что все компьютеры в одной сети

**Проблема:** База данных не создается  
**Решение:** Убедитесь, что есть права на запись в папку сервера
